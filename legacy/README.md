# Examer App (apps/)

แอปตรวจกระดาษคำตอบข้อเขียน Template 2 สำหรับโรงเรียน — มี 2 ฝั่งในแอปเดียว (เลือกตอนเปิดครั้งแรก เปลี่ยนได้ในตั้งค่า)
โมเดลรันในเบราว์เซอร์ทั้งหมด (ไม่มี server) รูปกระดาษไม่ออกจากเครื่อง

**ครูผู้สอน** (เน้นมือถือ) — สร้างการสอบ (วิชา · ห้อง · ประเภทคะแนน · เฉลย) แล้วทำ 3 ขั้น:
**① ถ่ายรูป** → **② ตรวจ/แก้** (เลือกเจ้าของแผ่นที่อ่านรหัสไม่ได้ + แตะตัวอักษรที่ระบบไม่แน่ใจ) → **③ คะแนน** (ส่งให้ฝ่ายวิชาการ · ไฟล์สำหรับ SGS/ปพ.5 · พิมพ์)
หน้าแรกบอก “ต้องทำอะไรต่อ” ของแต่ละการสอบ

**ฝ่ายวิชาการ** (เน้นคอม) — ภาพรวมทุกวิชา/ห้อง (ได้รับคะแนนแล้ว/รอครูส่ง) · ห้องเรียนและรายชื่อ · รายวิชาและครู · ข้อสอบกลาง · เกณฑ์ตรวจของโรงเรียน

**ส่งข้อมูลระหว่าง 2 ฝั่ง (ยังไม่มี server → ผ่านไฟล์ .json):**
ฝ่ายวิชาการ › รายวิชาและครู › “ไฟล์สำหรับครู” → ครู › ตั้งค่า › นำเข้า (ได้รายชื่อ, วิชา, ข้อสอบกลาง, เกณฑ์)
ครู › คะแนน › “สร้างไฟล์ส่งคะแนน” → ฝ่ายวิชาการ › ภาพรวม › นำเข้าไฟล์คะแนนจากครู

## เปิดใช้
ไม่ต้อง build แต่ต้องเปิดผ่าน http (Web Worker ใช้กับ `file://` ไม่ได้)
```bash
cd apps && python -m http.server 8080   # แล้วเข้า http://localhost:8080
```
หรือเปิดจาก GitHub Pages ของ repo · ครั้งแรกที่ถ่ายรูปจะดาวน์โหลดระบบตรวจประมาณ 40 MB (เบราว์เซอร์จำไว้)
อยากดูหน้าจออย่างเดียว → หน้าแรกกด “ลองดูด้วยข้อมูลตัวอย่างก่อน” · ตั้งค่า › ระบบตรวจ › **โหมดทดลอง** (ผลสุ่ม ไม่ต้องโหลดโมเดล)

## ระบบตรวจในเบราว์เซอร์ (engine)
| ขั้น | ทำงานด้วย | มาจาก |
|---|---|---|
| ① ตัดขอบ/ปรับภาพ ② หาช่อง + เตรียมภาพช่อง | โค้ด Python เดิมของ repo โมเดล รันด้วย **Pyodide + OpenCV** | ดึงจาก [67160328/Computer-Vision](https://github.com/67160328/Computer-Vision) ผ่าน jsDelivr (ปัก commit ไว้ใน `js/engine.js`) — ไม่ได้ก๊อปเข้า repo นี้ |
| ③ อ่านตัวอักษร A–Z, ตัวเลขรหัส, ช่องขีดฆ่า | โมเดล 3 ตัวแปลงเป็น **ONNX** รันด้วย onnxruntime-web | `engine/models/*.onnx` (แปลงจาก `.pt` ของ repo โมเดล) |

- `js/engine.js` → เรียก `js/engine-worker.js` (Web Worker) → `engine/examer_engine.py`
- `engine/torch/` = torch จำลอง (numpy) ให้โค้ด repo โมเดล import ได้ — ตัวโมเดลจริงไปรันที่ ONNX
- **ไม่ใช้** Top-3 Lexicon Refinement (ใช้เฉลยช่วยแก้คำ) — ส่งผลอ่านจริงให้หน้า app ให้คะแนนเอง และใช้ top-3 เป็นตัวเลือกให้ครูตอนตรวจทาน

ผลทดสอบ (ภาพ `data/Test` ของ repo โมเดล 8 แผ่น = 3,200 ช่อง):
- ผลอ่าน **ตรงกับ PyTorch 3,193/3,200 ช่อง** · 7 ช่องที่ต่างมาจาก OpenCV คนละเวอร์ชัน (Pyodide = 4.9, เครื่องที่ทดสอบ = 5.0) — รัน Python ด้วย OpenCV 4.9 ได้ผลเหมือนในเบราว์เซอร์
- โหลดครั้งแรก ~8 วินาที (ไม่นับเวลาดาวน์โหลด) · ตรวจ ~8–12 วินาที/แผ่น (Chromium, CPU)

## ออกแบบให้เข้ากับงานโรงเรียน
| เรื่อง | ทำอย่างไร |
|---|---|
| ครูทำงานน้อยที่สุด | 3 ขั้น + หน้าแรกบอกขั้นต่อไป · เฉลยวางจาก Word/Excel ได้ (บรรทัดละข้อ มีเลขข้อนำหน้าก็ได้) · มือถือมีแถบ 3 ขั้นด้านล่าง |
| ระบบโรงเรียนไทย | ปีการศึกษา/ภาคเรียน · ระดับชั้น · รหัสวิชา · ประเภท คะแนนเก็บ/กลางภาค/ปลายภาค · **แปลงคะแนน** (เช่น 20 ข้อ → เต็ม 10) · ไฟล์คะแนนเรียง ห้อง/เลขที่ สำหรับกรอก SGS / ปพ.5 |
| ข้อสอบกลาง | ฝ่ายวิชาการตั้งเฉลยครั้งเดียว ครูทุกห้องได้เฉลยเดียวกัน (ครูแก้เฉลยไม่ได้) |
| รายชื่อนักเรียน | ฝ่ายวิชาการวางจาก Excel ครั้งเดียว (เลขที่ · เลขประจำตัว · ชื่อ) ส่งให้ครูทุกคนผ่านไฟล์ |
| จับคู่กระดาษกับนักเรียน | จากเลขประจำตัวบนหัวกระดาษ — อ่านไม่ได้/ไม่อยู่ในรายชื่อ/ซ้ำ → “กระดาษที่ต้องจัดการ” ให้เลือกชื่อ |
| ใครยังไม่ส่ง | ตารางคะแนนแสดงทุกคนในรายชื่อ · ฝ่ายวิชาการเห็นจำนวนที่ยังไม่มีคะแนน |
| ตรวจ/แก้เร็ว | รูปลายมือจริงของช่อง + ตัวเลือก 3 อันดับจากระบบ (ไม่ใช้เฉลยช่วยเดา) แตะเดียวจบ |
| ภาษา | ใช้คำที่ครูใช้ (“ระบบไม่แน่ใจ”, “ตรวจ/แก้”, “ส่งคะแนน”) ไม่มีศัพท์เทคนิค · ตัวหนังสือ/ปุ่มใหญ่ |
| สแกนต่อเนื่อง | รูปเข้าคิวตรวจเบื้องหลัง ถ่ายต่อได้ทันที · ปิดหน้าแล้วเปิดใหม่ตรวจต่อ |
| ข้อมูลนักเรียน | อยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น · สำรอง/กู้คืนเป็นไฟล์ได้ในตั้งค่า |
| ภาพขนาดใหญ่ | เก็บไฟล์เดิม — ย่อเฉพาะภาพที่เกิน 4200 px / 8 MB (ย่อ/บีบซ้ำทำให้ผลอ่านช่องก้ำกึ่งเปลี่ยน) |

**ข้อจำกัดเพราะไม่มี server:** ครู/ฝ่ายวิชาการต้องส่งไฟล์กันเอง · ไม่มีบัญชีผู้ใช้/เชิญทางอีเมลจริง (ปุ่มอีเมลเปิดร่างให้ แนบไฟล์เอง) · ข้อมูลอยู่เครื่องเดียว

## โครงไฟล์
```
index.html, style.css
js/store.js          IndexedDB (ห้องเรียน, การสอบ, กระดาษ) + ตั้งค่า
js/engine.js         เรียกโมเดลในเบราว์เซอร์ · js/engine-worker.js  ตัวรันใน Web Worker
js/pipeline.js       Pipeline.run() จุดเดียวที่เรียกระบบตรวจ (docs/ENGINE.md) + โหมดจำลอง + เกณฑ์ให้คะแนน
js/school.js         รายชื่อจาก Excel, จับคู่นักเรียน, สรุปการสอบ, แปลงคะแนน, ไฟล์ส่งระหว่างครู↔วิชาการ
js/queue.js          คิวตรวจเบื้องหลัง (status: pending → done/error)
js/ui.js             ตัวช่วยวาดภาพ/ตัดช่อง/toast
js/view-home.js      เลือกบทบาท · หน้าแรกครู · ข้อมูลตัวอย่าง
js/view-examform.js  ฟอร์มการสอบ/ข้อสอบกลาง (วิชา · ห้อง · คะแนน · เฉลย)
js/view-exam.js      ครู: ถ่ายรูป → ตรวจ/แก้ → คะแนน
js/view-sheet.js     กระดาษแผ่นเดียว (แก้ช่องด้วยคีย์บอร์ด)
js/view-admin.js     ฝ่ายวิชาการ: ภาพรวม · ผลที่ครูส่ง · ข้อสอบกลาง · รายวิชาและครู
js/view-classes.js   ห้องเรียนและรายชื่อ
js/view-settings.js  ตั้งค่า (ตามบทบาท) · สำรอง/กู้คืน
js/app.js            router (#hash)
engine/              examer_engine.py, torch/ (จำลอง), models/ (ONNX + meta.json)
```
