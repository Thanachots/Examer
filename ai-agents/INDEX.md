# ai-agents/ — INDEX

ความจำร่วมของ agent (Claude, Copilot ฯลฯ) ที่ทีมใช้ทำโปรเจค Examer
agent จำข้ามแชทไม่ได้ จึงเก็บสิ่งที่ต้องรู้ไว้ที่นี่ — **agent ทุกตัวอ่านไฟล์นี้ก่อนเริ่มงาน**

## ลำดับอ่านตอนเริ่มแชท

> **ก่อนแก้ไฟล์ใดๆ: pull ก่อน** (สั่ง git เองไม่ได้ → เตือนผู้ใช้) · **ก่อนผู้ใช้ push: เช็กไฟล์ที่ไม่ควรขึ้น** · **ห้ามเขียนทับ GitHub** — รายละเอียด `rules.md` › Git  [claude/gelatin · 2026-10-19]

1. `INDEX.md` (ไฟล์นี้)
2. `rules.md` — กฎของโปรเจค
3. `decisions.md` — สิ่งที่ทีมตกลงกันแล้ว
4. `glossary.md` — คำเรียกที่ทีมใช้
5. `todo.md` — งานค้าง / ปัญหาที่ทุกคนต้องรู้
6. `<agent>/notes.md` — เรื่องเฉพาะ agent ของตัวเอง (เช่น `claude/notes.md`)
7. `<agent>/<ชื่อคน>/` ของผู้ใช้ที่กำลังคุยด้วย — `role.md` → chat log ล่าสุด → `private/` (ถ้ามี)

ไม่รู้ว่าคุยกับใคร → ถามชื่อผู้ใช้ก่อน แล้วหาโฟลเดอร์ของเขา

## โครงสร้าง

```
ai-agents/
├── INDEX.md            ไฟล์นี้
├── setup-memories.md   ไฟล์เสริมส่วนตัวคืออะไร + วิธีชวนผู้ใช้ทำ
├── rules.md            กฎของโปรเจค
├── decisions.md        สิ่งที่ตกลงแล้ว
├── todo.md             งานค้าง
├── glossary.md         คำเรียก
└── <agent>/
    ├── notes.md        เรื่องเฉพาะ agent นี้ ที่ทุกคนที่ใช้ agent นี้ต้องรู้
    └── <ชื่อคน>/
        ├── role.md          หน้าที่ของคนนี้ในทีม
        ├── <เลข>-<เรื่อง>.md  chat log
        └── private/         ไฟล์เสริมส่วนตัว (ไม่ขึ้น git) — ดู setup-memories.md
```

ผู้ใช้ใหม่ / agent ใหม่ → สร้างโฟลเดอร์ `<agent>/<ชื่อคน>/` ตามโครงนี้ได้เลย

## ไฟล์กลาง (ทุกไฟล์ที่อยู่ชั้นบนสุดของ ai-agents/) — ต้องติดป้ายคนแก้

ทุกครั้งที่เพิ่ม/แก้ ใส่ป้าย `[agent/ชื่อคน · วันที่]`

- ข้อในรายการ → ติดท้ายข้อ: `- ข้อความ  [claude/gelatin · 2026-10-19]`
- ตาราง → คอลัมน์ "โดย": `claude/gelatin`
- แก้ของคนอื่น → **ห้ามลบป้ายเดิม** เติมป้ายคนแก้ต่อท้าย: `[แก้ 0.6→0.55: copilot/somchai · 2026-10-21]`
- ข้อมูลเรื่องเดียวกันอยู่ที่เดียว ที่อื่นอ้างถึงแทนการก๊อป
- ของที่ไม่จริงแล้ว → แก้หรือขีดฆ่า (`~~ข้อความ~~`) พร้อมป้าย ไม่ลบเงียบๆ

## โฟลเดอร์ของแต่ละคน

| ไฟล์ | ต้องมี | ขึ้น git | เนื้อหา |
|---|---|---|---|
| `role.md` | ✓ | ✓ | รับผิดชอบส่วนไหน ไฟล์/โฟลเดอร์ไหน |
| chat log | ✓ | ✓ | ทำอะไรไป ตกลงอะไร ค้างอะไร — agent อัปเดตระหว่างคุย |
| `private/` | ไม่บังคับ | ✗ | ดู `setup-memories.md` |

**ชื่อ chat log:** ผู้ใช้ตั้งเองได้ · ค่าเริ่มต้น = agent ตั้งเป็น `<เลข>-<เรื่องที่คุย>.md`
เลข = แชทที่เท่าไหร่ของคนนี้ เรียง 2 หลัก (`01-setup-repo.md`, `02-app-screens.md`)
แชทใหม่ = เลขถัดจากไฟล์ล่าสุดในโฟลเดอร์
