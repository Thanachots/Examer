# setup-memories — ตั้งค่าความจำส่วนตัว (ไม่บังคับ)

บางคนในทีมเก็บข้อมูลเพิ่มไว้ใน `<agent>/<ชื่อคน>/private/` ให้ agent จำได้ข้ามแชท
และทำงานเข้ากับตัวเองมากขึ้น — **ไม่บังคับ** ใครจะมีหรือไม่มีก็ได้

## ตัวอย่าง (จาก `claude/gelatin/private/`)

| ไฟล์ | เก็บอะไร | ช่วยอะไร |
|---|---|---|
| `user-personality.md` | ผู้ใช้เป็นคนแบบไหน เช่น พิมพ์สั้น ชอบให้ถามเป็นตัวเลือก คำว่า "ไม่ๆ" แปลว่าเข้าใจผิด | agent ไม่ต้องเดานิสัยใหม่ทุกแชท |
| `reply-style.md` | อยากให้ agent ตอบแบบไหน เช่น สั้น ตอบตามเลขข้อ ไม่แปะโค้ด | ทุกแชทตอบเหมือนกัน |
| `workflow.md` | ทำงานยังไง เช่น commit เองหรือให้ agent ทำ ใช้เครื่องมืออะไร | agent ไม่ทำเกินหน้าที่ |

**ชื่อไฟล์และวิธีแบ่งตั้งเองได้** — ข้างบนเป็นแค่แบบที่ gelatin ใช้
จะรวมเป็นไฟล์เดียว มีแค่บางเรื่อง หรือมีเรื่องอื่นที่ไม่อยู่ในตารางก็ได้

## ไม่ขึ้น git

ทั้งโฟลเดอร์ `private/` อยู่ใน `.gitignore` (`ai-agents/*/*/private/`) — ข้างในตั้งชื่ออะไรก็ไม่หลุดขึ้น git
อยากแชร์ไฟล์ไหนให้คนอื่นดู → ย้ายออกมาไว้นอก `private/` หรือ `git add -f <ไฟล์>`

## agent ทำอะไร

- ผู้ใช้ยังไม่มี `private/` → **ถามง่ายๆ หนึ่งครั้ง** ตอนที่เหมาะ (เช่น หลังทำงานรอบแรกเสร็จ) ประมาณนี้:
  > "มีคนในทีมให้ agent จดนิสัย สไตล์การตอบ และวิธีทำงานไว้ จะได้ไม่ต้องบอกซ้ำทุกแชท
  > อยากลองทำบ้างไหม จะเอาเรื่องไหนบ้าง หรืออยากตั้งชื่อไฟล์เองก็ได้"
- ผู้ใช้ไม่เอา → **ห้ามถามซ้ำ ห้ามสร้างเอง** · จดไว้ใน `role.md` ของเขาว่า "ไม่ใช้ไฟล์เสริม" แชทหน้าจะได้ไม่ถาม
- ผู้ใช้เอา → สร้างเฉพาะเรื่องที่เขาเลือก ชื่อไฟล์ตามที่เขาตั้ง แล้วจดเพิ่มเองระหว่างทำงาน
- ไฟล์ใน `private/` ของคนอื่น → ไม่อ่าน ไม่แก้ (และปกติก็ไม่มีในเครื่องเรา)
