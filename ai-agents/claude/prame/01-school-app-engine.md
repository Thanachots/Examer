# 01 — หน้า app ตาม workflow โรงเรียน + โมเดลในเบราว์เซอร์ (2026-10-19)

## ทำอะไรไป
- ทำหน้า app ใหม่ใน `apps/`: ห้องเรียน (วางรายชื่อจาก Excel) · การสอบ 4 ขั้น เตรียม → สแกน → ตรวจทาน → คะแนน · หน้ากระดาษแผ่นเดียว (แก้ช่องด้วยคีย์บอร์ด) · ตั้งค่า
- จับคู่กระดาษกับนักเรียนจากรหัสบนหัวกระดาษ · คิว "กระดาษที่มีปัญหา" (อ่านรหัสไม่ได้ / ไม่อยู่ในรายชื่อ / ซ้ำ / ขาดหน้า) · ส่งออก CSV + พิมพ์
- ทำ engine ในเบราว์เซอร์: Pyodide รันโค้ด ①② เดิมของ repo โมเดล + ONNX 3 โมเดล (`apps/js/engine*.js`, `apps/engine/`)
- เคยทำ `server/` (FastAPI) → ลบทิ้งตาม `decisions.md` (ไม่มี server)
- ทดสอบ: ผลตรง PyTorch 3,193/3,200 ช่อง (`data/Test` 8 แผ่น) · ตรวจ ~8–12 วิ/แผ่น · flow ทั้งหมดใน Chromium ไม่มี error

## ตกลงอะไร
- ผู้ใช้เลือก: รันโมเดลในเบราว์เซอร์ตามทีม · UI ยังไม่เอาเข้า repo (ทำบน branch `feat/school-app` ในเครื่อง agent)

## ค้าง
- ผู้ใช้ตัดสินใจว่าจะส่ง branch `feat/school-app` เป็น PR เมื่อไหร่ (แก้ไฟล์ส่วนกลาง: `apps/js/pipeline.js`, `docs/ENGINE.md` → ต้องบอกทีมก่อน)
- เรื่องที่จดใน `todo.md`: ที่เก็บไฟล์ ONNX, commit ของ repo โมเดลที่ปักไว้, เวอร์ชัน OpenCV
