# CLAUDE.md — คำอธิบายโปรเจคสำหรับ Claude / AI ผู้ช่วย

> ไฟล์นี้เขียนให้ AI ผู้ช่วย (Claude Code / Claude) อ่านก่อนเริ่มงานในโฟลเดอร์นี้ · คนอ่านด้วยได้ แต่คู่มือสำหรับคนคือ `DEV_GUIDE.md`

## โปรเจคคืออะไร
EXAMER: ระบบตรวจกระดาษคำตอบเขียนมือ "Template 2" (Rayong MARCO) · รับรูปถ่ายมือถือ 1 แผ่น → คำตอบ 20 แถว × 20 ช่อง (ช่องละตัวอักษร A–Z)
บนกระดาษมี: หมุดดำ 3 มุม (มุมขวาบนมีเลข "2") · ขีดดำซ้าย–ขวา 20 คู่ · ตาราง 20 × 20 (ช่องกว้าง ~98 px บนหน้าสแกน 2480×3508)
นักเรียนอาจ: เขียนในช่อง · เขียนทับเส้น (ตัวไม่ตรงช่อง) · ขีดฆ่าตัวผิดแล้วเขียนต่อ · เขียนล้นกรอบ
ทีมคุยกันเป็นภาษาไทย · ตอบผู้ใช้เป็นภาษาไทย สั้น ตรง

## ลำดับการทำงาน (pipeline) และไฟล์ที่ "ใช้จริง" ตอนนี้
```
รูป → Phase 1 สแกน → 2A หาตาราง → 2B ว่าง/ตัวอักษร/ขีดฆ่า → Phase 3 แยกหมึก+อ่าน A–Z → รวมผล v3 → JSON
```
| ขั้น | ไฟล์ที่ใช้จริง (canonical) | หมายเหตุ |
|---|---|---|
| Phase 1 | `phase1/phase1_v4_locked.py` (`run_v4(img, ref)`) + `bars_ref.json` | import v3 → v2 → v1 ต่อกัน · ห้ามแก้ไฟล์ `_locked` |
| 2A | `phase2/phase2a_locked.py` (`detect(scan)`) | หาเส้นตารางด้วย morphology · ไม่มีการเทรน |
| 2B | `model/examer/models/m2b_v3.onnx` (จาก `phase2b/v3/m2b_v3_locked.pt`) | อินพุต N×1×96×56 (ภาพบริบทรอบช่อง · ดู `_ctx`) · คลาส 0 ว่าง 1 ตัวอักษร 2 ขีดฆ่า |
| Phase 3 | `phase3/run/p3lib_v5.py` (`letters(scan, rows)`) + `model/examer/models/m3_az.onnx` (จาก `phase3/data/m3_all2.pt`) | แยกหมึกออกจากเส้นด้วยสี/รูปทรง แล้ว CNN อ่าน 48×48 |
| รวมผล | `model/examer/pipeline.py` → `combine_v3` | อ่านทุกแถวด้วย Phase 3 v5 · ใส่ช่องตามตำแหน่งจริง (จุดกลางตัวอักษร) · ช่องที่ 2B ว่าขีดฆ่า → ทิ้งตัวอักษรในช่องนั้น |

**จุดเข้าใช้งาน:** `model/examer/pipeline.py: read_sheet(img_bgr) → dict` · CLI `model/run.py` · เว็บ `examer_web/examer.js: Examer.read(file)`
**ตรรกะรวมผลมี 2 สำเนา ต้องแก้ให้ตรงกันเสมอ:** `model/examer/pipeline.py` และ `examer_web/py/web_pipeline.py` (ตัวเว็บเป็น async เพราะเรียก onnxruntime-web ผ่าน JS)

## รูปแบบผล (JSON)
`rows[i].mode == "cell"` → `cells` 20 ค่า: `"A"–"Z"` · `""` ว่าง · `"-"` ขีดฆ่า · `"?"` ไม่มั่นใจ (< 0.8) ส่งครูตรวจ
`rows[i].mode == "line"` (ทั้งแถวเขียนทับเส้น) → `letters` = ลำดับตัวอักษรซ้าย→ขวา ไม่ระบุช่อง
เปลี่ยนรูปแบบนี้ = กระทบแอปของทีม (`public/`, `examer_web/`) · ถามก่อนเปลี่ยน

## กติกาที่ต้องทำตาม (ตัวเลขในรายงานพึ่งกติกานี้)
1. **ห้ามแก้ไฟล์ที่ชื่อลงท้าย `_locked` หรือโมเดลที่มี sha256 ใน `LOCK_*`/`SHA256SUMS.txt`** · จะเปลี่ยน → สร้างเวอร์ชันใหม่ (เช่น `phase1_v5.py`) แล้ววัดใหม่
2. แบ่ง Train / Val / Test ก่อน · ปรับโค้ดด้วย Dev/Val เท่านั้น · ล็อก sha256 แล้วรัน Test **ครั้งเดียว** · ห้ามแก้หลังเห็นผล Test
3. **ถามผู้ใช้ก่อนใช้ชุด Test / ชุดวัดผลทุกครั้ง** · ข้อมูลที่เคยใช้หาจุดบกพร่องแล้ว → รายงานเป็น "ผลหลังแก้" ไม่ใช่ผลอิสระ
4. ตรวจของจริงก่อนสรุป (เปิดไฟล์ ดูภาพผล) · อย่าเดาจากชื่อไฟล์หรือวันที่
5. บอกข้อจำกัดตรงๆ · อย่าอ้างตัวเลขที่ได้จากข้อมูลที่ใช้พัฒนาเป็นผลจริง

## จุดอ่อนที่รู้แล้ว
- 2B ทายตัว I / H / F / G ที่ช่องแรก/ช่องสุดท้ายว่าขีดฆ่า (7 จาก 4,000) — ข้อผิดที่ระบบไม่รู้ตัวที่เหลืออยู่
- แถวทับเส้นที่เขียนเบียด/คร่อมแถว: ตัวขาด/เกิน
- ยังไม่อ่านช่องรหัสนักเรียน / วงกลมเลือกชุดข้อสอบ
- เว็บช้า ~20–90 วินาที/แผ่น
- ไฟล์กลางการเทรนบางตัวไม่มีในเครื่อง ต้องสร้างใหม่: `phase2b/v3/ctx_all.npz` (`phase2b/v2/build_ctx.py` — path ข้างในยังชี้โฟลเดอร์ cloud ต้องแก้ก่อน) · `phase3/data/train/letters.npz` (`phase3/run/run_p12.py train` → `extract_train.py train`)
