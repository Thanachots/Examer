# Phase 2B v2 — แก้ที่ต้นเหตุ (เขียนก่อนเทรน · 26 ต.ค. 2569)

ต้นเหตุ: 2B v1 เห็นแค่ภาพในกรอบช่อง (64×64) → บนแผ่นเขียนทับเส้น ขีดนอนของ I/T/H ที่อยู่ในกรอบดูเหมือนขีดฆ่า เพราะมองไม่เห็นส่วนที่เหลือของตัวอักษรนอกกรอบ
และข้อมูลเทรน v1 ไม่มีแผ่นเขียนทับเส้นเลย

แก้: (1) ภาพเข้า = ช่อง + ขยายซ้าย/ขวา 10% และบน/ล่าง 75% ของความสูงช่อง → ย่อเป็น 56×96 (กว้าง×สูง) — เห็นตัวอักษรทั้งตัว
      (2) เพิ่มแผ่นเขียนทับเส้น Train 30 แผ่น (ไม่มีขีดฆ่า: ว่าง/ตัวอักษรตามหมึกในกรอบ) + ขีดฆ่าสังเคราะห์บนตัวทับเส้น
      สถาปัตยกรรม CNN และป้ายแผ่นเขียนในช่องเหมือน v1 ทุกอย่าง (ป้าย test ตรงกับ v1: 5021 / 7070 / 309)

ข้อมูล: เทรน = ในช่อง train 146 + ทับเส้น Train 30 · เลือก epoch = ในช่อง Val 33 + ทับเส้น Val 10
ไม่ใช้: ในช่อง Test 31 (ใช้เช็กซ้ำหลังล็อกเท่านั้น) · IMG_5417 / 8029 / 5415 / 5416 / 5418 / 5419 / 9722 (เช็กหลังล็อก)

เกณฑ์เลือก epoch (Val): ต้องได้ recall ขีดฆ่าในช่อง ≥ 99% ก่อน → แล้วเลือก epoch ที่ (ขีดฆ่าหลอกบนทับเส้น Val น้อยสุด) ถ้าเท่ากันเลือก macro F1 ในช่องสูงสุด
หลังล็อก: รันในช่อง Test ครั้งเดียว (เช็กซ้ำ — ชุดนี้เคยใช้วัด v1 แล้ว) · เลขจริงมาจากแผ่นใหม่ 20 แผ่นของเพื่อน
