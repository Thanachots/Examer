# ต้นเหตุผลต่ำ 20 แผ่น + แนวทางพัฒนาต่อ (วิเคราะห์หลังเห็นผล · ไม่แก้โค้ด)

## พังกี่แผ่น
Nice (คนใหม่): **10/10 แผ่น** ระบบรวม 83.4–85.6% · แถวในช่อง 67.7–74.1% → พังเหมือนกันทุกแผ่น (เป็นปัญหาของระบบ ไม่ใช่รูปบางรูป)
Korn: 10/10 แผ่นอยู่ 89.5–94.9% · ส่วนที่ต่ำคือแถวทับเส้น (86–92.5%)
Phase 1 / 2A ไม่ใช่ต้นเหตุ: QC ผ่านทุกแผ่น · ได้ 20×20 ทุกแผ่น

## ต้นเหตุ 1 (หลัก · Nice แถว 1–10): ตัวขีดฆ่าถูกผ่าเป็น 2 ตัว → ตัวปกติข้างหลังเลื่อนช่องทั้งแถว
- ช่องที่ผิด Nice 1,033 ช่อง = ตัวปกติทั้งหมด (ช่องขีดฆ่าผิด 0) · ทั้ง 1,033 อยู่หลังช่องขีดฆ่าที่ถูกผ่า
- Phase 3 (p3lib_v5 letters) มีกฎ "ก้อนกว้าง > 1.9 เท่าค่ากลางของแถว = 2 ตัวติดกัน → ผ่าครึ่ง"
- ตัวขีดฆ่าของ Nice กว้าง ~80 px (เส้นขีดยาวเกือบเต็มช่อง) ตัวปกติ ~32 px → ถูกผ่า 278/298 ช่อง · Korn ขีดสั้น ~61 px → ถูกผ่า 22/301
- system.assign จับคู่ซ้าย→ขวา ช่องละ 1 ตัว ห้ามย้อน → ชิ้นที่เกินยึดช่องถัดไป → ทุกตัวหลังจากนั้นเลื่อน 1 ช่อง / ชนกันเป็น "?"
- ต้นเหตุเชิงระบบ: ข้อมูล "ช่องนี้ขีดฆ่า" จาก 2B ถูกใช้ **หลัง** จับคู่ ไม่ได้ใช้ตัดหมึกก่อน Phase 3 แยกตัวอักษร
- ทำไมไม่เจอก่อนหน้า: Phase 3 พัฒนาบนแผ่นทับเส้น (ไม่มีขีดฆ่า) · 2B วัดเดี่ยว · แผ่น "ในช่อง + ขีดฆ่า" ไม่เคยผ่านระบบรวมจนชุดนี้

## ต้นเหตุ 2 (แถว 11–20 ทับเส้น): อ่านถูก แต่แปลงเป็นคำตอบรายช่องเสีย
- Phase 3 อ่านแถวทับเส้นถูก 99.29% (Nice) / 97.85% (Korn) แต่ระบบรวมเหลือ 95.89% / 89.24%
- เหตุผล "?" ที่มากสุด = "มีหลายตัวในช่องเดียว" (Korn 91 · Nice 32): เขียนทับเส้นแถวละ 20 ตัวแต่ตัวไม่ตรงช่อง/คร่อมแถว → 2 ตัวตกช่องเดียว → ระบบส่งครูตรวจ
- Korn เขียนเบียดและคร่อมแถวมากกว่า Nice จึงเสียมากกว่า

## ส่วนที่ทำงานดี (เลขจริง)
Phase 1 20/20 · 2A 20/20 · 2B 99.95% / 99.70% · ขีดฆ่าเจอ 599/599 · Phase 3 อ่านช่องปกติ 100% · อ่านทับเส้น 97.9–99.3%

## แนวทางพัฒนาต่อ
1. ส่งช่องขีดฆ่าจาก 2B เข้า Phase 3: ลบหมึกในช่องขีดฆ่าก่อนแยกตัวอักษร (แก้ต้นเหตุ 1 ที่ต้นทาง)
2. แผ่นเขียนในช่อง: อ่านรายช่องตรงๆ (crop ช่อง → CNN) แทนการแยกตัวอักษรทั้งแถวแล้วจับคู่กลับ
3. กฎผ่าก้อนกว้าง: เทียบกับความกว้างช่อง (~98 px) แทนค่ากลางของแถว
4. แถวทับเส้น: เก็บคำตอบเป็น "ลำดับตัวอักษรต่อแถว" ไม่บังคับลงรายช่อง / ให้ assign ย้อนได้เมื่อชนกัน
5. ข้อมูลพัฒนา: เพิ่มแผ่นที่มีขีดฆ่าหลายแบบ (2 เส้น ยาวเต็มช่อง) และรันทั้งระบบระหว่างพัฒนา ไม่วัดแยกเฟสอย่างเดียว
6. วัดใหม่ด้วยแผ่นชุดใหม่ (ไม่ใช้ 20 แผ่นนี้ซ้ำ)
