# Examer Web (ต้นแบบ)

หน้าเว็บสำหรับอัปโหลดภาพกระดาษคำตอบ Template 2 แล้วดูผลทั้ง 3 ส่วน:
① ตัดขอบ/ปรับภาพ → ② จับช่อง → ③ อ่านตัวอักษร → ผลคะแนน

## เปิดใช้
ไม่ต้อง build — เปิด `index.html` ในเบราว์เซอร์ได้เลย หรือ

```bash
cd web && python -m http.server 8080   # แล้วเข้า http://localhost:8080
```

## สถานะ
- **โหมดจำลอง:** ยังไม่มีโมเดล ผลทั้ง 3 ส่วนเป็นข้อมูลสร้างขึ้นใน `js/pipeline.js`
- UI ที่ใช้งานได้จริง: อัปโหลด, before/after, ตาราง 20×20, แก้ช่องด้วยมือ (ครูตรวจซ้ำ), ให้คะแนนเทียบเฉลย, export JSON/CSV

## ต่อ backend
ตั้ง `API_URL` ใน `js/pipeline.js` → เว็บจะส่งภาพไป `POST {API_URL}/grade` (field `image`)
backend ต้องตอบ JSON รูปแบบเดียวกับ `mockResult()` (ดูคอมเมนต์ `Result` ในไฟล์)

## เกณฑ์ที่ใช้ตอนนี้ (ตาม README หลัก ส่วนที่ 4)
- ข้ามช่องว่างและช่องขีดฆ่า แล้วต่อตัวที่เหลือเป็นคำ · พิมพ์เล็กนับเป็นพิมพ์ใหญ่
- confidence < 0.6 → "รอครูตรวจ" (ค่านี้ต้องหาจากการทดลอง)
- ไม่ตอบ = ผิด · ข้อที่ไม่มีเฉลยไม่นับ
- **ยังไม่ได้ตกลง:** เว้นช่องกลางคำ — ตอนนี้ต่อกันเลย
