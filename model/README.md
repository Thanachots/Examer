# model/ — โมเดลอ่านกระดาษคำตอบ (Template 2) สำหรับเอาไปทำแอป

ใส่รูปถ่ายกระดาษคำตอบ 1 รูป → ได้คำตอบทั้ง 20 แถว × 20 ช่อง เป็น JSON

```
รูปถ่าย → Phase 1 สแกน → 2A หาตาราง → 2B ว่าง/ตัวอักษร/ขีดฆ่า → Phase 3 อ่าน A–Z → คำตอบ
```

## ลองรัน (Python 3.10+)

```bash
cd model
pip install -r requirements.txt
python run.py samples/IMG_9855.jpg --viz ผล.jpg
```

ได้ไฟล์ `samples/IMG_9855.json` (คำตอบ) และ `ผล.jpg` (ภาพที่วาดคำตอบทับ) · รับ jpg / png / heic (iPhone) · ใส่ชื่อโฟลเดอร์แทนชื่อรูปเพื่ออ่านทีละหลายรูป
ใช้เวลาประมาณ 15–20 วินาทีต่อรูปบน CPU

เรียกจากโค้ด:

```python
from examer import read_sheet, load_image
R = read_sheet(load_image('รูป.jpg'))
```

## ผลที่ได้ (JSON)

```json
{
  "ok": true,
  "rows": [
    {"row": 1, "mode": "cell", "cells": ["-", "A", "B", "C", "", "?", ...], "conf": [...], "boxes": [[x0,y0,x1,y1], ...]},
    {"row": 11, "mode": "line", "letters": ["Q", "R", "S", ...], "conf": [...], "boxes": [...]}
  ],
  "needs_review": 7,
  "phase1": {"path": "paper", "qc_px": 4.55},
  "qc_warning": false
}
```

| ค่า | ความหมาย |
|---|---|
| `mode: "cell"` | แถวที่เขียนตัวละช่อง → `cells` มี 20 ค่า ตรงกับช่องที่ 1–20 |
| `mode: "line"` | แถวที่เขียนทับเส้น → `letters` = ตัวอักษรเรียงซ้ายไปขวา (ไม่ระบุช่อง เพราะเขียนไม่ตรงช่อง) |
| `"A"`–`"Z"` | ตัวอักษรที่อ่านได้ |
| `""` | ช่องว่าง |
| `"-"` | ช่องที่ถูกขีดฆ่า (ไม่นับ) |
| `"?"` | ไม่มั่นใจ (< 0.8) → **ให้ครูตรวจเอง** |
| `needs_review` | จำนวน `"?"` ทั้งแผ่น |
| `qc_warning` | `true` = สแกนคลาดเกิน 8 px → ควรให้ผู้ใช้ถ่ายใหม่หรือลากมุมเอง |
| `boxes` | กรอบบนหน้าสแกน 2480×3508 (ใช้วาดผลบนจอ) |
| `ok: false` | อ่านไม่ได้ · ดูข้อความใน `error` |

## ไฟล์ข้างใน

| ไฟล์ | คืออะไร |
|---|---|
| `run.py` | ตัวรันจากบรรทัดคำสั่ง |
| `examer/pipeline.py` | ต่อทุกเฟสเข้าด้วยกัน · ระบบรวม v3 (`combine_v3`): อ่านทุกแถวด้วย Phase 3 v5 แล้วใส่ช่องตามตำแหน่งจริง · ช่องขีดฆ่าทิ้งตัวอักษรในช่องนั้น |
| `examer/phase1/` | Phase 1 v4: ตัด ตั้ง ลบเงา แก้กระดาษโค้ง |
| `examer/phase2/` | Phase 2A: หาตาราง 20 × 20 จากเส้นพิมพ์ |
| `examer/phase3/` | Phase 3 v5: แยกหมึกออกจากเส้นตาราง |
| `examer/models/m2b_v3.onnx` | 2B: ว่าง / ตัวอักษร / ขีดฆ่า (เข้า 1×96×56) |
| `examer/models/m3_az.onnx` | อ่าน A–Z (เข้า 1×48×48) |
| `SHA256SUMS.txt` | ค่า hash ของไฟล์ที่ใช้วัดผลในรายงาน · **อย่าแก้ไฟล์เหล่านี้** ไม่งั้นตัวเลขในรายงานจะไม่ใช่ของโค้ดนี้ |

ใช้แค่ numpy + OpenCV + onnxruntime (ไม่ต้องมี PyTorch) จึงรันในเบราว์เซอร์ผ่าน Pyodide + onnxruntime-web ได้แบบเดียวกับ `public/engine/`

## ความแม่นยำ

| ส่วน | ผล |
|---|---|
| Phase 1 สแกน | รูปถ่ายชุดใหม่ 60/60 · 20 แผ่นทดสอบ 20/20 |
| 2A หาตาราง | Test 330 แผ่น หาแถวเจอ 100% · 20 แผ่นทดสอบ 20/20 |
| 2B ว่าง / ตัวอักษร / ขีดฆ่า | 20 แผ่นทดสอบ ถูก 99.70–99.95% · จับขีดฆ่าได้ 599/599 |
| อ่าน A–Z (แผ่นทับเส้น) | Test 10 แผ่น CAR 99.12% |

ทั้งระบบ (CAR = ตัวอักษรถูก · "?" นับเป็นผิด):

| ชุด | ระบบรวม v2 (26 ต.ค.) | **ระบบรวม v3 (ตัวนี้)** |
|---|---|---|
| 20 แผ่น A–Z คนเขียนใหม่ (Nice) | 99.16% | **99.21%** |
| 20 แผ่น A–Z คนเดิม (Korn) | 98.35% | **98.32%** |
| 2 แผ่นเขียนคำ (40 คำ · 262 ตัว) | 95.42% · คำถูก 31/40 | **99.62% · คำถูก 39/40** |

v3 ไม่มีจุดไหนตอบผิดเองเพิ่มจาก v2 (ที่ลดลงใน Korn คือ 1 ช่องที่เปลี่ยนเป็น "?" ส่งครูตรวจ)

**ข้อควรรู้:** ทุกชุดในตารางนี้เคยใช้หาจุดบกพร่องของรุ่นก่อนมาแล้ว จึงเป็น "ผลหลังแก้" ยังไม่ใช่ผลทดสอบอิสระ · ต้องยืนยันกับแผ่นใหม่

## ข้อจำกัด

- ใช้ได้กับกระดาษ Template 2 เท่านั้น (ต้องเห็นหมุดดำ 3 มุม และขีดดำซ้าย–ขวา)
- ขีดฆ่าที่ทดสอบแล้วคือเส้นนอน 1–2 เส้น · ยังไม่ได้ทดสอบขีดแบบซิกแซก / ระบายทึบ / กากบาท
- ตัว I / H / F / G ที่เขียนชิดขอบตารางบางครั้งถูกมองเป็นขีดฆ่า (7 ช่องจาก 4,000 ในการทดสอบ) — เป็นข้อผิดพลาดที่ระบบไม่รู้ตัวเพียงแบบเดียวที่เหลือ
- แถวทับเส้นที่เขียนเบียดหรือคร่อมแถว อาจมีตัวขาด / เกิน
- ยังไม่อ่านช่องรหัสนักเรียนและวงกลมเลือกชุดข้อสอบ
